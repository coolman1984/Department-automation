# HR Attendance Control

برنامج محلي بسيط لمتابعة الحضور اليومي من ملف إكسل. يعمل بدون إنترنت بعد استخراج الحزمة وتشغيل `START.bat` على ويندوز.

الإصدار الحالي يقرأ شيت `TIM_02_DailyAttendance`، ويعرض الحضور والغياب والإجازات والتأخير والإضافي المؤهل. يحفظ تاريخ الرفع محليًا، ويمنع تكرار نفس محتوى الملف حتى لو تغيّر اسمه، ويحافظ على آخر نتيجة سليمة لو وصل ملف غير مطابق.

ابدأ من [دليل المستخدم](USER_GUIDE.md). ولتغيير منطق البيانات أو توسيع المشروع، اقرأ [دليل المشروع](PROJECT_GUIDE.md) ثم سجل القرارات في `project_memory/PROJECT_LOG.md`.

هذه النسخة هي أساس الحضور فقط. ربط الموظفين والورديات والإجازات واحتياج العمالة في رفع واحد متعدد الملفات هو المرحلة التالية، وليس وظيفة مدعاة في الإصدار الحالي.
