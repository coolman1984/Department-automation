# بيانات التجربة الصناعية

الملفات تحت `hr-factory-synthetic-dataset/` هي نفس محتويات حزمة بيانات الموارد البشرية الصناعية، مفكوكة داخل الريبو حتى يقدر أي موديل يقرأها ويختبرها مباشرة.

- `01_CLEAN_BASELINE/`: الحالة النظيفة المتوقعة.
- `02_STRESS_DIRTY/`: نسخة بها حالات صعبة وأخطاء مقصودة لاختبار التحمل.
- `00_DOCUMENTATION/`: قاموس البيانات وفهرس الاختبارات.

هذه البيانات وهمية بالكامل، ولا يجب استبدالها بأي بيانات موظفين حقيقية داخل ريبو عام.
